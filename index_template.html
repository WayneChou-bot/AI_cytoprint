驗證：已知機制對得上嗎？ 用我的特徵，不是官方 profile

AMG900（Aurora 激酶抑制劑）→ 核面積中位數 1389 vs DMSO 934（+49%）、細胞數僅 40%。 符合教科書：Aurora 抑制 → 胞質分裂失敗 → 多倍體巨核。

FK-866（NAMPT 抑制劑）→ 核面積 451（−52%）、細胞數 38%。 符合 NAD 耗竭 → 凋亡 → 核濃縮。

quinidine（離子通道阻斷劑）→ 核面積 928 ≈ DMSO 934、細胞數 99%，幾乎無表型。
兩個最強表型的核大小變化方向相反、且各自符合已知機制——這是自建管線有效的最直接證據。 注意：每個化合物只有 1 個 field，無實驗重複，故僅為案例佐證、非統計推論。

    06 · AI 能加什麼？可落地的功能設計

    表徵學習 embedding

    • 自監督影像編碼器：用 DINO/DINOv2 或 masked autoencoder 直接從五通道影像學 embedding，超越手工 CellProfiler 特徵
    • 弱監督對比學習：以「同擾動為正對」訓練，讓同 MoA 更靠近
    • 產出可直接餵給下游檢索的 128–512 維指紋

    批次去偏 debiasing

    • 依 subset 不同：JUMP compound=featureselect+Harmony、CRISPR=sphering+Harmony+PCA、ORF=sphering+Harmony（各另有 interpretable 版）
    • 以 DMSO 對照做 typical-variation normalization；sphering 需正則化/降維避免放大噪訊
    • 雙向驗證：生物保存用 MoA/target 檢索 mAP；批次移除用 kBET / iLISI / plate-label 檢索（kBET 是量批次混合、不是生物保存指標）；並用 source-aware block bootstrap 給 CI

    檢索與解釋 UX

    • 以圖找相似藥：上傳/選一個擾動，秒回最近鄰與推測 MoA（本頁雛形）
    • 向量資料庫（FAISS）撐 10 萬級擾動即時檢索
    • LLM 助手：把最近鄰、共享 target 與文獻整理成一段機制說明
    07 · 差異化定位與路線圖
    • 避開紅海：不做「分子結構 → 性質預測」那種過度 benchmark 的題目，改做表徵學習＋檢索——輸入是細胞影像，不是分子式。
    • 切入點：形態指紋的 MoA 檢索 / 批次去偏 / 以圖找相似藥；solo 玩家少、CV 技能可直接用、資料真實龐大。
    • 路線圖：① 本雛形（CellProfiler 特徵＋最近鄰）→ ② 加 sphering/Harmony 去偏、用 mAP 驗證 → ③ 換自監督影像 embedding → ④ 擴到 JUMP cpg0016 全量、建 FAISS 檢索與 LLM 機制解說。
    • 可展示成果：互動檢索網頁（本頁）、去偏前後的 mAP 改善曲線、MoA 混淆矩陣、案例研究（如紫杉醇 → 微管群）。
