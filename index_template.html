MorphoProfile · 細胞影像形態分析 · Image-Based Morphological Profiling

用開源 Cell Painting 細胞影像的「形態指紋」做作用機制（MoA）相似度檢索、候選活性篩選與去偏方法比較。 本頁的影像分割、UMAP、檢索、指紋與統計皆由真實資料預先計算（離線 Python），瀏覽器只讀取結果繪圖；附完整資料來源與一鍵可重現程式。 Morphological fingerprints from open Cell Painting images, used for mechanism-of-action (MoA) similarity retrieval, candidate-activity screening and a batch-correction comparison. Segmentation, UMAP, retrieval, fingerprints and statistics are all pre-computed offline in Python from real data; the browser only renders the results. Full data sources and one-command reproducibility included.

影像看得到、標註看不到的機制：以 paclitaxel（紫杉醇） 為查詢，形態最相近的第一名是 KX2-391——資料庫把它標為「Src 抑制劑」， 但 KX2-391（tirbanibulin）其實同時是微管聚合抑制劑，會造成與紫杉醇類似的有絲分裂/微管表型；第二名 CYT-997 則是道地的微管抑制劑。 這正是 image-based drug discovery 的價值：不需知道分子式，看細胞長相就能指出真正的作用機制，甚至補正不完整的文獻標註。 Mechanism the image sees but the annotation misses: querying with paclitaxel, the closest morphological neighbour is KX2-391 — labelled a "Src inhibitor" in the database, yet KX2-391 (tirbanibulin) is in fact also a tubulin-polymerization inhibitor, producing a mitotic/microtubule phenotype much like paclitaxel's. The runner-up, CYT-997, is a bona fide tubulin inhibitor. This is exactly the value of image-based drug discovery: without knowing the molecular structure, cell appearance alone points to the real mechanism — and can even correct incomplete literature annotations.
05 · 候選活性篩選 × 方法表現（真實）05 · Candidate-activity screen × method performance (real)

候選活性篩選Candidate-activity screen 共識指紋偏離 DMSO 的程度consensus deviation from DMSO

候選活性比例Candidate-active fraction
門檻（DMSO null 第 95 百分位）Threshold (DMSO null, 95th pct)
以每個化合物的共識指紋與 DMSO 對照中心的 L2 距離為活性分數；門檻取自「只用 DMSO 隨機五孔中位數」的虛無分布第 95 百分位。 這是啟發式篩選、不是顯著性檢定（未做 plate-matched null、未白化、無 per-compound p/FDR）；嚴謹版應改用 copairs replicate mAP＋permutation p-value＋FDR。 多數 Repurposing-Hub 化合物在 A549、此劑量下活性溫和，候選比例落在兩、三成屬合理。 Activity score = L2 distance of each compound's consensus fingerprint from the DMSO centroid; the threshold is the 95th percentile of a DMSO-only null (medians of random 5-well groups). This is a heuristic screen, not a significance test (no plate-matched null, no whitening, no per-compound p-value/FDR); the rigorous version would use copairs replicate mAP + permutation p-values + FDR. Most Repurposing-Hub compounds are only mildly active in A549 at this dose, so a candidate fraction in the twenties/thirties is reasonable.

Modest but clearly above chance — and that gap is the point of attack: stronger representations (self-supervised embeddings) and validated batch correction can push it up (see the comparison below — de-biasing must be measured, and its effect depends on the setup). This is the differentiated direction, away from the crowded "molecule → property prediction" space.

    06 · AI 能加什麼？可落地的功能設計06 · What AI adds: deployable feature design

    表徵學習 embeddingRepresentation learning

    • 自監督影像編碼器：用 DINO/DINOv2 或 masked autoencoder 直接從五通道影像學 embedding，超越手工 CellProfiler 特徵Self-supervised encoders: learn embeddings directly from 5-channel images with DINO/DINOv2 or a masked autoencoder, going beyond hand-built CellProfiler features
    • 弱監督對比學習：以「同擾動為正對」訓練，讓同 MoA 更靠近Weakly-supervised contrastive learning: treat replicates of the same perturbation as positive pairs so same-MoA compounds pull together
    • 產出可直接餵給下游檢索的 128–512 維指紋Outputs a 128–512-D fingerprint that feeds straight into retrieval

    批次去偏 debiasingBatch de-biasing

    • 依 subset 不同：JUMP compound=featureselect+Harmony、CRISPR=sphering+Harmony+PCA、ORF=sphering+Harmony（各另有 interpretable 版）Differs per subset: JUMP compound = feature-select + Harmony; CRISPR = sphering + Harmony + PCA; ORF = sphering + Harmony (each also has an interpretable variant)
    • 以 DMSO 對照做 typical-variation normalization；sphering 需正則化/降維避免放大噪訊Typical-variation normalization against DMSO controls; sphering needs regularization/dimension reduction so it does not amplify noise
    • 雙向驗證：生物保存用 MoA/target 檢索 mAP；批次移除用 kBET / iLISI / plate-label 檢索（kBET 量的是批次混合、不是生物保存）；並用 source-aware block bootstrap 給 CIValidate on both axes: biology retention via MoA/target retrieval mAP; batch removal via kBET / iLISI / plate-label retrieval (kBET measures batch mixing, not biology retention); with source-aware block-bootstrap CIs

    檢索與解釋 UXRetrieval & explanation UX

    • 以圖找相似藥：上傳/選一個擾動，秒回最近鄰與推測 MoA（本頁雛形）Find similar drugs by image: pick or upload a perturbation, get nearest neighbours and an inferred MoA instantly (prototyped on this page)
    • 向量資料庫（FAISS）撐 10 萬級擾動即時檢索Vector database (FAISS) to serve real-time retrieval over 100k+ perturbations
    • LLM 助手：把最近鄰、共享 target 與文獻整理成一段機制說明LLM assistant that summarises retrieved neighbours, shared targets and literature into a mechanism narrative
    07 · 差異化定位與路線圖07 · Positioning & roadmap
    • 避開紅海：不做「分子結構 → 性質預測」那種過度 benchmark 的題目，改做表徵學習＋檢索——輸入是細胞影像，不是分子式。Avoid the crowded space: not another "molecular structure → property prediction" benchmark. This is representation learning + retrieval, and the input is a cell image, not a formula.
    • 切入點：形態指紋的 MoA 檢索 / 批次去偏 / 以圖找相似藥；solo 玩家少、CV 技能可直接用、資料真實龐大。The angle: MoA retrieval, batch de-biasing and image-based drug similarity on morphological fingerprints — few solo developers work here, CV skills transfer directly, and the data is real and large.
    • 路線圖：① 影像→自建指紋（已完成）→ ② CellProfiler profiles＋最近鄰檢索（已完成）→ ③ 雙指標＋block CI 的去偏驗證（已完成，含真實 JUMP-Target）→ ④ 自監督影像 embedding → ⑤ 擴到 JUMP cpg0016 全量、建 FAISS 檢索與 LLM 機制解說。Roadmap: ① image → own fingerprint (done) → ② CellProfiler profiles + nearest-neighbour retrieval (done) → ③ dual-metric, block-CI de-biasing validation (done, including real JUMP-Target) → ④ self-supervised image embeddings → ⑤ scale to full JUMP cpg0016 with FAISS retrieval and an LLM explanation layer.
    • 可展示成果：互動檢索網頁（本頁）、自建影像管線重現已知機制、去偏雙指標權衡圖（含 CI）、案例研究（紫杉醇 → 微管群）。Demonstrable output: this interactive app, an in-house image pipeline that recovers known biology, a dual-metric de-biasing trade-off figure with CIs, and case studies (paclitaxel → tubulin cluster).
