image-based morphological profiling

MorphoProfile · 細胞影像形態分析 · Image-Based Morphological Profiling

一個關於「平均方式、估計量與實驗設計如何扭曲科學結論」的案例研究，用真實的開源 Cell Painting 資料一路走完。 載體是細胞影像「形態指紋」的作用機制（MoA）相似度檢索、候選活性篩選與去偏方法比較。 本頁的影像分割、UMAP、檢索、指紋與統計皆由真實資料預先計算（離線 Python），瀏覽器只讀取結果繪圖；附完整資料來源與一鍵可重現程式。 A case study in how averages, estimators and experimental designs distort scientific conclusions, worked through end to end on real open Cell Painting data. The vehicle is morphological fingerprinting for mechanism-of-action (MoA) similarity retrieval, candidate-activity screening and a batch-correction comparison. Segmentation, UMAP, retrieval, fingerprints and statistics are all pre-computed offline in Python from real data; the browser only renders the results. Full data sources and one-command reproducibility included.

影像看得到、標註看不到的機制：以 paclitaxel（紫杉醇） 為查詢，形態最相近的第一名是 KX2-391——資料庫把它標為「Src 抑制劑」， 但 KX2-391（tirbanibulin）其實同時是微管聚合抑制劑，會造成與紫杉醇類似的有絲分裂/微管表型；第二名 CYT-997 則是道地的微管抑制劑。 這正是 image-based drug discovery 的價值：不需知道分子式，看細胞長相就能指出真正的作用機制，甚至補正不完整的文獻標註。 Mechanism the image sees but the annotation misses: querying with paclitaxel, the closest morphological neighbour is KX2-391 — labelled a "Src inhibitor" in the database, yet KX2-391 (tirbanibulin) is in fact also a tubulin-polymerization inhibitor, producing a mitotic/microtubule phenotype much like paclitaxel's. The runner-up, CYT-997, is a bona fide tubulin inhibitor. This is exactly the value of image-based drug discovery: without knowing the molecular structure, cell appearance alone points to the real mechanism — and can even correct incomplete literature annotations.
05 · 候選活性篩選 × 方法表現（真實）05 · Candidate-activity screen × method performance (real)

候選活性篩選Candidate-activity screen 共識指紋偏離 DMSO 的程度consensus deviation from DMSO

候選活性比例Candidate-active fraction
門檻（DMSO null 第 95 百分位）Threshold (DMSO null, 95th pct)
以每個化合物的共識指紋與 DMSO 對照中心的 L2 距離為活性分數；門檻取自「只用 DMSO 隨機五孔中位數」的虛無分布第 95 百分位。 這是啟發式篩選、不是顯著性檢定（未做 plate-matched null、未白化、無 per-compound p/FDR）；嚴謹版應改用 copairs replicate mAP＋permutation p-value＋FDR。 多數 Repurposing-Hub 化合物在 A549、此劑量下活性溫和，候選比例落在兩、三成屬合理。 Activity score = L2 distance of each compound's consensus fingerprint from the DMSO centroid; the threshold is the 95th percentile of a DMSO-only null (medians of random 5-well groups). This is a heuristic screen, not a significance test (no plate-matched null, no whitening, no per-compound p-value/FDR); the rigorous version would use copairs replicate mAP + permutation p-values + FDR. Most Repurposing-Hub compounds are only mildly active in A549 at this dose, so a candidate fraction in the twenties/thirties is reasonable.
