18,000 wells · 50 plates（= block）· 50-D 共同空間 · plate-block bootstrap 1000 draws（生物軸）。
生物軸 = MoA 檢索 mAP（越高越好）；批次軸 = plate-mixing enrichment（→1 越好，>1 表仍有批次結構）。
方法生物訊號 mAP（95% CI）批次混合（95% CI）
●raw（標準化）0.087 [0.08, 0.096]2.42 [2.07, 2.77]

誠實解讀（已修掉極端值污染後重算）：三種方法的生物訊號幾乎相同（mAP raw 0.087 / sphered 0.087 / +Harmony 0.095；兩兩 paired block Δ 的 95% CI 都跨 0，即無顯著差異）。批次軸上 Harmony 明顯改善混合（2.42× → 1.63×，往 1 靠），且在此樣本量下測不到生物損失——「測不到」不等於「沒有代價」；單獨球化則略微變差。

教訓：去偏必須同時看「生物保存」與「批次移除」兩軸，並用 plate-block bootstrap 與 paired Δ CI。本結果為單一中心 pilot、批次效應本就小，故差異多不顯著，不能一般化；同一引擎（jump_mvp.py）跑的 CPJUMP1 pilot 同樣是單一 source，且 plate 與 cell line、timepoint 混雜（見主頁 05c）。真正的多來源校正（以 source 為 block）仍是未來工作，本 repo 尚未示範。

（對照：先前「Harmony 兩軸皆輸」是資料污染的假象，清理後結論反轉——正說明資料品質與嚴謹評估缺一不可。）
